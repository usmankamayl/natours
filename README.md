# 🌿 Natours — Adventure Tours Landing Page

> Лендинг туристического агентства **Natours** для любителей активного отдыха на природе. Сайт построен на **Flexbox**, насыщен **CSS-анимациями** и интерактивностью на **чистом JavaScript**.

🔗 **[Посмотреть сайт](https://usmankamayl.github.io/natours/)**

## 🛠️ Технологии

| Технология | Описание |
|---|---|
| **HTML5** | Семантическая структура страницы |
| **CSS3 / Flexbox** | Вся раскладка построена на Flexbox |
| **CSS Animations** | Keyframe-анимации, transitions, transform |
| **Vanilla JS** | Интерактивность без библиотек и фреймворков |
| **CSS Pseudo-elements** | `::before`, `::after` для декоративных эффектов |
| **CSS Variables** | Переменные для единой цветовой схемы |

---

## ✨ Особенности проекта

- 🟢 **Flexbox-раскладка** — всё позиционирование через современный Flex
- 🎬 **CSS-анимации** — плавные появления элементов при загрузке страницы
- 🃏 **Flip-карточки туров** — 3D-переворот карточек при наведении (CSS transform)
- 🖼️ **Hover-эффект фотографий** — секция «О нас» с наложением изображений
- 🎥 **Видео-фон** — секция Stories с фоновым видео
- 💬 **Отзывы** — карточки с цитатами и фото клиентов
- 🔖 **Popup-модалка** — форма бронирования открывается через якорную навигацию на чистом JS
- 📋 **Форма бронирования** — с кастомными radio-кнопками и валидацией
- 🔗 **Плавная навигация** — переходы по секциям через Vanilla JS
- 📱 **Адаптивность** — корректное отображение на разных экранах

## 🎨 Анимации

| Элемент | Анимация |
|---|---|
| Заголовок Hero | Вылет слева/справа при загрузке (`@keyframes`) |
| CTA-кнопка | Появление снизу + pulse при hover |
| Навигация | Плавное появление при скролле |
| Карточки туров | 3D flip при наведении |
| Фото в секции «О нас» | Scale + overlap при hover |
| Кнопки | Подъём (`translateY`) + тень при hover |

## 📚 Что реализовано / Чему научился

- Построение сложных раскладок на **Flexbox**
- CSS **keyframe-анимации** и `transition` для UI-эффектов
- **3D-трансформации** через `perspective` и `rotateY`
- Работа с **псевдоэлементами** для декора
- Открытие/закрытие **popup** через `target` CSS и Vanilla JS
- Работа с **видео** (`<video>`) в качестве фонового элемента
- Кастомные **radio-кнопки** и стилизация форм
